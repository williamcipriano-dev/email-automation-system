# Email Automation System

Projeto de automação de emails desenvolvido com Python.

## Funcionalidades

- Envio automático de emails via SMTP
- Leitura automática da caixa de entrada via IMAP
- Filtros inteligentes de emails
- Estrutura modular
- Configuração segura com variáveis de ambiente

## Tecnologias utilizadas

- Python
- smtplib
- imap-tools
- python-dotenv

## Estrutura do projeto

```bash
services/
├── email_sender.py
└── email_reader.py
```
